# Text Replacer

A lightweight, fast CLI tool written in Rust that performs text replacements based on rules defined in a CSV file (`list.csv`). It supports processing text directly from the **system clipboard** or reading/writing to **files**. The original idea of this is to censor the personal info in the text while using AI, and when writing the template configuration to put here, I realize it can be used to fix capitalization issues and abbreviations. That's the reason the configuration file is be like that.

## Features

- **Clipboard Mode (Default):** Reads text directly from your clipboard, replaces patterns, and writes the result back into your clipboard.
- **File Mode:** Reads from an input file, applies replacements, and writes to an output file.
- **CSV Rule Engine:** Define all your find-and-replace rules in a simple `list.csv` file.

---

## Configuration (`list.csv`)

You can edit `list.csv` file in the root/working directory to manage the text you want to replace. Each line should contain a `search_pattern` and a `replacement` separated by a comma.

For example, when configure like this:

```csv
im ,I'm 
Foo, [name]
Bar, [surname]
```

and input this:

```
im Foo Bar.
```

The output will be:

```
I'm [name] [surname].
```

## Build & Release

To compile an optimized binary for standalone use:

```bash
cargo build
```

The compiled executable will be located at:
```text
./target/debug/
```

*(Make sure `list.csv` is in the same working directory when executing the binary).*

## Usage

### 1. Clipboard Mode (Default)

If no file-related flags are passed, the program operates in clipboard mode:

```bash
# Windows
.\target\debug\ReadFileAndReplaceString.exe

# Linux / macOS
./target/debug/ReadFileAndReplaceString
```
*(Or simply run `cargo run`)*

* **Input:** Current system clipboard text.
* **Output:** Replaced text is automatically copied back to your clipboard.

### 2. Default File Mode (`workspace.txt`)

To read from and write to the default `./workspace.txt` file, pass `f`:

```bash
# Windows
.\target\debug\ReadFileAndReplaceString.exe f

# Linux / macOS
./target/debug/ReadFileAndReplaceString f
```
*(Or run `cargo run -- f`)*

### 3. Custom File Mode

You can specify custom input and/or output paths using `-i` and `-o`:

* **Specify both input and output files:**
  ```bash
  ./target/debug/ReadFileAndReplaceString -i input.txt -o output.txt
  ```
  *(Or: `cargo run -- -i input.txt -o output.txt`)*

* **Specify only an input file** (outputs to `./workspace.txt`):
  ```bash
  ./target/debug/ReadFileAndReplaceString -i input.txt
  ```
  *(Or: `cargo run -- -i input.txt`)*

* **Specify only an output file** (reads from `./workspace.txt`):
  ```bash
  ./target/debug/ReadFileAndReplaceString -o output.txt
  ```
  *(Or: `cargo run -- -o output.txt`)*

### CLI Arguments Summary

| Flag | Argument | Description |
| :--- | :--- | :--- |
| *(None)* | — | Clipboard mode (Reads from & writes to clipboard). |
| `f` | — | File mode using default `./workspace.txt` as input and output. |
| `-i` | `<path>` | Sets the input file path (enables file mode). |
| `-o` | `<path>` | Sets the output file path (enables file mode). |

You can also use the given script to run the program.

Clipboard Mode: `inClipboard.bat` or `inClipboard.sh`  
Default File Mode: `inFile.bat` or `inFile.sh`
